A DER Submission & Hygiene Checks
01

RM Raises DER

Relationship Manager creates a DER and selects the inventory unit(s) being transacted.

02

Upload Identity Document

Passport required for all projects. For Iraq projects, the National ID copy is mandatory and the passport becomes optional.

03

OCR Extraction

Document is read automatically and key fields are captured.

OCR Passport Number · OCR Passport Name · OCR Nationality

04

Document Type Valid?

Confirms the upload is genuinely a passport or, for Iraq projects, a national ID — not merely that a file is attached.

Yes — continue No — Blocked
05

RM Reviews & Amends Captured Info

RM has the option to change the OCR-captured information before submission.

06

OCR Info Matches Amended Info?

The OCR-extracted values and the RM's amended values are validated against one another before submission is allowed.

Yes — continue No — Blocked
07

Agency Type Derived

Set automatically from the Agency Account's Record Type. Defaults to "Direct" where the Agency field is blank.

08

RM Makes Selections

Token Exception, Rebate, DLD Waiver, Price Discount, and DP Hold Needed For (15 / 30 / 45 / 60 / 75 / 90 days).

09

DP Hold Needed For Selected?

Where a value is selected, the RM enters the corresponding payment-days schedule before proceeding.

Yes — enter schedule, continue No — continue directly
10

Submit DER

System summarizes RM Selected Info on a unit-wise basis and writes it to the DER's RM Selected Info field.

B HOD Discount Authorization Matching
11

Match Active DER_Authorization_Rule__c

Evaluated against Deal Type, Country, Construction Status, Type of Inventory, Bedroom Type Exclusions, Building Code, and Price Range.

12

Rule Matched & Key Unique?

A given Building Code + Bedroom Type key (e.g. DDA#Studio) may be active on only one DER_Authorization__c record at a time.

Yes — continue No — Manual Review
13

Total Discount Within Max Authority %?

DLD Waiver + Rebate + Price Discount, together with any Token Exception and DP Hold terms, checked against the matched Authorization's Max Authority %.

Yes — Auto-Approved No — Manual Review
Blocked
Submission prevented. RM must correct the flagged item before resubmitting.
Manual Review
Routed to MIS for standard approval, unchanged from the current process.
Auto-Approved
DER Status = Approved. No MIS review required.
Reflects Section 3, "Defining the Process," of the DER Technical Design Document (Demand Ref MID OFFICE/2026/38020). Steps 04, 06, 12, and 13 are the four points at which the process can end without reaching Auto-Approved.
